# histora-health.github.io

The public page for [Histora Health](https://github.com/histora-health).

Static, hand-written, no build step. `assets/site.css` is shared with
[Evolving Agents Labs](https://github.com/EvolvingAgentsLabs/evolvingagentslabs.github.io)
so the two read as one visual family — same type scale, same neutrals with a
slight hue bias toward the accent, same light and dark tokens.

To change what is listed, edit `index.html`. There is one entry and it should
stay that way until there is a second thing worth reading.

Apache 2.0.

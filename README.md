# histora-health.github.io

The public page for [Histora Health](https://github.com/histora-health).

Static, hand-written, no build step. `assets/site.css` is shared verbatim with
[Evolving Agents Labs](https://github.com/EvolvingAgentsLabs/evolvingagentslabs.github.io)
so the two read as one visual family — same type scale, same neutrals biased
toward the accent, same light and dark token sets.

The page states what the published work found, including the measurement that
argues against it: enforcement can turn a correct refusal into a legal write on
the wrong record. That is deliberate. A page about a safety mechanism that only
reports its wins is the kind nobody should believe.

To change what is listed, edit `index.html`. One entry, and it stays one until
there is a second thing worth reading.

Apache 2.0.
